# Installed tier

**Tier:** Escape Hatch (Free)
**Version:** 1.0.0

## Included in this tier

- All supported notes apps: Evernote, Google Keep, Notion, Zoho Notebook, Joplin, Simplenote, Bear, Standard Notes, Obsidian, UpNote, MyScript Notes, Zoom notes, OneNote, Apple Notes, and a general path for others — each with a backup guide and cancel guide (`notes-apps`)
- Reading notes through a connector (Evernote, Notion, Zoom) or by opening the app's export directly (best for small and medium exports)
- Sorting into Work / Personal / Not sure / Sensitive (the Work bucket can use the user's business name)
- Sensitive-note protection: ask each time, locked file, printable sheet, delete-after cleanup
- Destination: **Claude-ready files** (Markdown files plus a tracker, ready to add to a Claude Project) — skill `claude-ready`
- Backup guide, backup check, cancel guide, savings counter
- Voice-friendly mode
