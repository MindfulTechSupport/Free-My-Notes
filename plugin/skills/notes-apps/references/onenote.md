# OneNote

## How Claude gets the notes
PDF or Word exports of each section (Claude reads these), or The Great Escape's Autopilot.

## The full backup
In **OneNote for Windows** (the desktop app):
1. **File → Export**.
2. Choose **Notebook** and **OneNote Package (.onepkg)** for a complete backup you can reopen in OneNote. Save it in a backup folder, plus a second copy.
3. For copies Claude can read: export each **Section** as **PDF** or **Word**, into the same folder.

Source: Microsoft Q&A, "OneNote and Exporting/Saving Notebooks" (June 2025).

## What's in it
The .onepkg holds everything but only opens in OneNote. The PDF or Word files hold each section's pages; Claude reads them, but handwriting and drawings come through as pictures.

## Notebooks are called
Notebooks, divided into sections, then pages.

## Canceling
OneNote is free; it's also part of Microsoft 365. Only cancel Microsoft 365 if the user doesn't need Word, Excel, Outlook, or the storage.

## Watch out for
- Work or school accounts may block exporting a whole notebook; then it's one section at a time.
- The OneNote web app has fewer export options; use the Windows app where possible.
