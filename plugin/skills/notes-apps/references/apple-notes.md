# Apple Notes

## How Claude gets the notes
Apple Notes has no built-in way to export all notes at once (Zapier, January 2024). Three ways:
1. **A few notes:** on a Mac, open each note → **File → Export as PDF…**.
2. **Everything, with a Mac export app:** apps from the Mac App Store (Zapier mentions one called Exporter) save the whole library as Markdown or HTML. Claude reads those.
3. **The Great Escape:** Autopilot exports the notes for the user on their Mac.

## The full backup
Use option 2 or 3 into a backup folder, plus a second copy. iCloud already syncs the notes, but that isn't a copy you control.

## What's in it
Markdown or HTML files (option 2), or PDFs (options 1 and 3), organized by folder.

## Notebooks are called
Folders (in iCloud or On My Mac), plus tags.

## Canceling
Apple Notes is free. iCloud+ storage is for everything on the account; only change it if the user doesn't need the space.

## Watch out for
- **Locked notes** must be unlocked before they can be exported.
- Shared notes and folders belong partly to other people; ask before copying them somewhere shared.
