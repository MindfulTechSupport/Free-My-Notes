# UpNote

## How Claude gets the notes
The backup.

## The full backup
1. In the UpNote desktop app, look for **Export** (in the File menu or Settings) and choose all notes.
2. Pick **Markdown** (best for Claude) or HTML.
3. Save into a backup folder, plus a second copy.

## What's in it
One file per note, organized by notebook, with images alongside.

## Notebooks are called
Notebooks (nested), plus tags.

## Canceling
UpNote Premium is bought through the app store or UpNote's website; cancel there if it's a subscription.

## Watch out for
- Locked notebooks need unlocking first.
