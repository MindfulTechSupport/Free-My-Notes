# Standard Notes

Standard Notes is encrypted and open source; Proton bought it in April 2024 (TechRadar).

## How Claude gets the notes
The backup.

## The full backup
1. In Standard Notes, open **Preferences → Backups** (the name may vary slightly by version).
2. Download a **decrypted** backup. An encrypted backup can't be read by anyone without the account password, including Claude.
3. Keep it in a backup folder, plus a second copy. It contains every note in readable form, so store it as carefully as the account.

## What's in it
One text file of data holding every note (title, text, dates) and tag.

## Notebooks are called
Tags (and nested tags). Treat the first tag as the notebook.

## Canceling
Paid plans are billed in the Standard Notes account (or the app store if bought on a phone).

## Watch out for
- If the backup comes out encrypted, Claude can't read it. Ask the user to download the decrypted one.
- Notes made with special editors (spreadsheets, task lists) may come out as data rather than plain text; copy what's readable and say so.
