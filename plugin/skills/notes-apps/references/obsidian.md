# Obsidian

## How Claude gets the notes
The vault folder itself. Obsidian notes are already Markdown files on the user's computer.

## The full backup
1. In Obsidian, find the vault's folder (Settings → Files and links, or right-click the vault name → Reveal in Finder / Show in Explorer).
2. Copy the whole folder (or zip it) into a backup folder, plus a second copy somewhere else.

## What's in it
Every note as a .md file, in the user's own folders, with images and files wherever the vault keeps attachments. Some notes start with a front-matter block (tags, dates, aliases).

## Notebooks are called
Folders.

## Canceling
Obsidian is free. Only Obsidian Sync or Publish are paid; cancel them in the Obsidian account if no longer needed.

## Watch out for
- Links between notes look like `[[Note name]]`; keep them as they are when copying to Markdown places.
- The `.obsidian` folder is settings, not notes; skip it.
