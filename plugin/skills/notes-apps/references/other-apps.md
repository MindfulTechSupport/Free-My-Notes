# Any other notes app

Most notes apps have an export. When the user's app isn't in the list:

1. **Look for it:** Settings, Account, or the File menu, under words like Export, Backup, Download my data, or Takeout. Search "<app name> export all notes" on the app's help site.
2. **Pick the most complete readable format:** Markdown, HTML, or JSON (with attachments) beat PDF; PDF beats nothing.
3. **No export at all?** Options: a PDF of each note (slow but complete), the app's sharing or email feature, or The Great Escape's Autopilot.
4. **Canceling:** find where they pay (the app's website, Apple, or Google Play) using the same steps as `evernote.md`.

Tell the user honestly when an app makes leaving hard, and send feedback if they'd like the app added to Free My Notes.
