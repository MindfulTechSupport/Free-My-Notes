# Notion

## How Claude gets the notes
- **The Notion connector** (Claude's Settings → Connectors → Notion). Claude can search and read the pages the user shares with it.
- **Or the backup** (Markdown & CSV export), which is better for "everything at once."

## The full backup (export)
1. In Notion on a computer, open **Settings** and look for **Export all workspace content** (in the workspace's general settings). For one page and everything under it instead: open the page → **⋯** → **Export**.
2. Choose **Markdown & CSV**, include subpages, and include files and images.
3. Notion prepares a .zip; big workspaces email a download link.
4. Keep the zip in a backup folder, plus a second copy.

## What's in it
Each page as a Markdown file and each database as a CSV, in folders that mirror the page tree. File and folder names end in a long code (for example `Recipes 1a2b3c…`); that code isn't part of the title. Images and files sit next to the pages that use them.

## Notebooks are called
Pages and sub-pages (and databases). Treat each top-level page as a notebook.

## Canceling
Paid plans are billed in Notion's Settings → Billing (or through the app store if bought on a phone). Downgrading to Free keeps the pages.

## Watch out for
- Very large workspaces can take a long time to export; export one top-level page at a time if it fails.
- Databases come out as CSV tables: copy them as tables, one note per database.
