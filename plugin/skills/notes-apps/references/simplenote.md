# Simplenote

## How Claude gets the notes
The backup.

## The full backup
1. In Simplenote on a computer or the web app, look for **Export Notes** (the File menu in the desktop app; Settings → Tools on the web).
2. It downloads a .zip. Keep it in a backup folder, plus a second copy.

## What's in it
A zip with each note as a text file, and a `source/notes.json` file holding every note with its tags and dates (active and trashed notes listed separately). Source: Standard Notes help, "How can I import my notes from Simplenote?"

## Notebooks are called
Simplenote has no notebooks, only **tags**. Treat each tag as a notebook (first tag wins) and untagged notes as "Simplenote (no tag)".

## Canceling
Simplenote is free; there's nothing to cancel.

## Watch out for
- A note's first line is its title.
- Some notes are written in Markdown; keep the formatting as it is.
