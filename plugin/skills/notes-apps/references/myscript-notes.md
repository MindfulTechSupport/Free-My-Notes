# MyScript Notes (formerly Nebo)

## How Claude gets the notes
The backup: MyScript's own exports, one folder at a time.

## The full backup
1. In MyScript Notes, open a folder and use **Select notes**, select all, then **Export**. (You can only export notes from one folder at a time.) For one note: open it → **⋯** → **Export**.
2. Choose the format by note type:
   - **Documents** (typed or converted handwriting): **Word (.docx)** or **Text** — Claude reads these best. PDF also works.
   - **Notebooks and boards** (freeform handwriting): **PDF**, PNG, or SVG.
   - Also export a **.nebo** copy of each folder if the user may want to reopen them in MyScript Notes later.
3. Repeat for each folder. Keep everything in a backup folder, plus a second copy.

Source: MyScript help, "Export and share."

## What's in it
Word or text files read cleanly. Handwritten pages come out as PDFs or pictures: Claude can look at them, but they copy as pages, not editable text.

## Notebooks are called
Folders, holding notes (documents, notebooks, boards, PDFs).

## Canceling
Bought through the app stores; cancel any subscription there.

## Watch out for
- Folder-by-folder export takes a while for big libraries; The Great Escape's Autopilot can click through it.
