# Bear

## How Claude gets the notes
The backup.

## The full backup
1. In Bear on a Mac (or iPhone/iPad), select all notes (⌘A on a Mac).
2. **File → Export Notes…** and choose **TextBundle** (keeps images and files with each note) or **Markdown**.
3. Save into a backup folder, plus a second copy.

Bear's own backup file (for restoring into Bear) isn't readable by other apps; use the export.

## What's in it
One Markdown file (or a .textbundle folder with the text and its images) per note. Tags are written inside the notes as #tags.

## Notebooks are called
Bear uses **tags** (including nested tags like #work/clients) instead of notebooks. Treat the first tag as the notebook.

## Canceling
Bear Pro is a subscription through the Apple App Store: iPhone Settings → their name → Subscriptions → Bear → Cancel.

## Watch out for
- Locked notes (Bear Pro) need unlocking before export.
