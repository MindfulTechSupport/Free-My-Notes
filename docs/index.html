Nine steps to freedom

Stop anytime and pick up later. A short progress log remembers where you are, never what's in your notes.

  1. Connect Evernote
  2. Survey every notebook
  3. Sort work from personal
  4. Lock up sensitive notes
  5. Copy to where you want
  6. Back up (.enex export)
  7. Check the backup
  8. Cancel & see your savings
  9. Clean up the sensitive copies

Your passwords stay private

Logins, account numbers, and ID scans never go into Claude Projects or memory. It asks you about each one, keeps them in a locked spot, and deletes them once you've moved them to a password manager.

Work and personal, apart

It sorts every note into Work, Personal, Not sure, and Sensitive, so your business notes and your recipes don't end up in the same place.

Nothing gets lost

Every note is counted at the start and checked at the end. Your full backup is verified before you cancel. The plugin never deletes your notes.

Ready to work with in Claude

Your notes come out as tidy files, one per notebook, ready to drop into a Claude Project and finally do something with those ideas.

Talks you through it

Plain language, one question at a time. In voice mode, or when you say "I'm driving," it keeps going and gives you spoken updates.

Shows you the savings

When you cancel, it tells you what you're saving every month and every year. Nice escape.

Built from a real escape

Install it

You'll need a computer for this step. The Claude phone app can't install a plugin from a file. Once it's on your account, you can talk to it from your phone too.

Free: add the marketplace

  1. In the Claude desktop app or claude.ai, open Customize → Plugins.
  2. Add a marketplace and enter MindfulTechSupport/Escape-from-Evernote
  3. Install escape-from-evernote.

Claude Code: /plugin install escape-from-evernote --marketplace MindfulTechSupport/Escape-from-Evernote

Any version: install from a file

  1. Download the .plugin file (free, or the one from your purchase).
  2. In Claude, open Customize → Plugins.
  3. Remove an older Escape from Evernote if it's listed, then upload the file.

Then connect the Evernote connector in Claude (Settings → Connectors), start a new chat, and say "escape Evernote."
