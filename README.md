# Free My Notes
*A Claude plugin by Mindful Tech Projects*

Get every note out of your notes app, safely (Evernote, Google Keep, OneNote, Apple Notes, Notion, and more), or keep a backup you control.

Version 1.0.0 is in review and will be published here soon. Website: https://freemynotes.com
